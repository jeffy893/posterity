## File Naming Convention

Files follow the pattern: `YYYY-MM-DD_Title_Description.ext`

This provides chronological ordering and makes it easy to trace the evolution of ideas over time.

---

## File Types

- `.md` — Markdown files containing the full text of works (readable on GitHub)
- `.pdf` — Formatted documents, often with visual elements or formal layouts
- `.png` / `.jpeg` — Images, diagrams, and visual works
